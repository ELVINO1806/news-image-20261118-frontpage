# News Image 20261118 — 18 November 2026 World-News Front Page

A program that draws the 18 November 2026 world-news front page as one PNG. It lays out the day's top stories across six continents as a single newspaper-style front page image.

It works using Python 3.13 standard library only, with a hand-rolled PNG encoder and a hand-rolled bitmap font. The output is deterministic: the same code always produces the same image, with no external assets, fonts, or network calls.

## Run

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
